# GS Quant Risk Lab

## 무엇을 만든 것인가

`/gs-lab.html`은 기존 S&P 500 종목 점수판과 분리된 미국 자산 포트폴리오 위험 분석 화면이다. 수익률 순위나 매수 신호를 추가하지 않고, 사용자가 정한 비중이 변동성·낙폭·시장 베타·상관관계·손실 꼬리에 어떤 영향을 주는지 확인하는 데 목적이 있다.

화면의 기본 예시는 최근 검토 바스켓인 CVX, PEP, TLT, SPGI, KMB, PRU, WFC, PG, VICI를 합계 100%로 구성한다. 이는 증권계좌 보유 내역이 아니며, 사용자가 직접 수정하거나 기존 `내 포트`의 미국 자산만 불러와 다시 100%로 정규화할 수 있다.

## gs-quant 사용 경계

- 계산 엔진은 Apache-2.0으로 공개된 [`goldmansachs/gs-quant`](https://github.com/goldmansachs/gs-quant) 2.1.6의 시계열 통계 함수를 사용한다.
- 로컬에서 사용하는 범위는 수익률, 실현 변동성, 베타, 상관계수, 최대낙폭이다.
- Goldman Sachs Marquee 기관용 API의 client ID 또는 secret은 사용하지 않는다.
- 파생상품 가격결정, 기관 리스크 서비스, Goldman Sachs 내부 데이터·전략·주문 시스템에는 연결되지 않는다.
- 이 프로젝트는 Goldman Sachs의 제휴·승인 제품이 아니며, 공개 SDK의 분석 개념과 함수를 활용한 개인 연구 도구다.

공식 문서에서 포트폴리오 계산과 시나리오 컨텍스트는 각각 [Portfolios](https://developer.gs.com/docs/gsquant/pricing-and-risk/portfolios/)와 [Scenarios](https://developer.gs.com/docs/gsquant/pricing-and-risk/scenarios/)에 설명되어 있다. 공식 예제의 일부는 Marquee 세션과 권한이 필요하므로 이 로컬 서비스가 동일한 기관 결과를 재현한다고 해석하면 안 된다.

## 데이터와 계산 계약

시장 가격은 Yahoo Finance를 `yfinance`로 조회한 배당·분할 조정 일별 종가다. Yahoo/yfinance는 편의 공급자이며 거래소나 SEC 공식 원천이 아니다. 모든 자산과 벤치마크에 공통으로 존재하는 완료 거래일이 60개 미만이면 분석하지 않는다. 뉴욕 정규장 당일 일봉은 변동 중인 값을 위험 통계에 섞지 않도록 16:15(미 동부시간) 전까지 제외한다. API 응답은 조회 시각, 가격 기준일, 기간, 조정 정책, 관측치 수, 세션 정책, 계산 버전과 경고를 함께 반환한다.

포트폴리오는 매 거래일 입력 비중으로 재조정된다는 단순화(`daily_constant_weight`)를 사용한다. 주요 계산은 다음과 같다.

- 일별 포트 수익률: 각 자산 일별 수익률의 입력 비중 가중합
- 연환산 변동성: 일별 표준편차 × `sqrt(252)`
- 최대낙폭: 누적지수의 직전 고점 대비 최대 하락률
- 베타: 포트 수익률과 벤치마크 수익률의 공분산 ÷ 벤치마크 분산
- Sharpe: 연환산 포트 수익률에서 입력 무위험수익률을 뺀 뒤 연환산 변동성으로 나눈 값
- 95% 역사적 VaR: 일별 수익률 하위 5% 분위수의 손실 크기
- 95% Expected Shortfall: VaR 경계 이하 일별 손실의 평균 크기
- 위험기여도: 공분산 행렬과 입력 비중으로 계산한 한계 분산 기여도의 비율

충격 슬라이더는 `포트 추정 충격 = 과거 베타 × SPY 충격`인 1차 근사다. 종목별 기여는 `비중 × 종목 베타 × SPY 충격`으로 표시한다. 급변 구간의 상관·베타 변화, 옵션의 비선형성, 유동성, 세금, 수수료, 환율과 체결 충격은 반영하지 않는다.

## API

`POST /api/gs-quant/analyze`

```json
{
  "positions": [
    {"symbol": "CVX", "weight_pct": 50},
    {"symbol": "TLT", "weight_pct": 50}
  ],
  "benchmark": "SPY",
  "lookback": "3y",
  "risk_free_rate_pct": 4.0
}
```

제약:

- 미국 티커 2~12개, 중복 불가
- 모든 비중은 양수이며 합계는 100% ±0.5% 이내
- 조회 기간은 `1y`, `3y`, `5y`
- 무위험수익률은 연 `0~20%`
- 비교 가능한 일별 관측치가 부족하면 값을 추정하지 않고 오류 또는 `null`과 경고를 반환

응답의 `schema_version`은 `gs-risk-lab-v1`이다. `engine`, `data`, `formula` 메타데이터를 수치와 함께 보존해야 하며, 클라이언트는 누락값을 0으로 바꾸지 않는다.

## 운영 및 보안

- API 키를 브라우저에 넣지 않는다. 현재 기능에는 Marquee 자격증명이 필요하지 않다.
- 기존 개인 접근 토큰을 켠 서버에서는 새 정적 화면과 API도 동일한 인증 경계를 따른다.
- 분석은 주문을 만들거나 전송하지 않는다.
- 실제 투자 전 최신 공시, 공식 시세, 상품 설명서와 본인의 손실 감내 수준을 별도로 확인한다.
